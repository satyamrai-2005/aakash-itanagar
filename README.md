## Live deployment
Recommended simple route: GitHub repository -> GitHub Pages -> custom domain.

1. Create a GitHub account.
2. Create a public repository, e.g. `aakash-itanagar`.
3. Upload all files while preserving folders.
4. Open Repository Settings -> Pages.
5. Select the `main` branch and `/ (root)` as the publishing source.
6. Save and wait for deployment.
7. Add the approved custom domain under Pages -> Custom domain.
8. Configure the DNS records at your domain provider exactly as GitHub instructs.
9. Enable Enforce HTTPS after the certificate is available.
10. Test mobile, forms, phone links, WhatsApp links and every page.
